# Smart Planner

Smart Planner is a modern and responsive productivity web application designed to help users efficiently organize tasks, manage schedules, and plan daily activities through an integrated calendar-based task management system.
The application combines the functionality of a to-do list with an interactive calendar interface, allowing users to create, view, manage, and organize tasks according to specific dates and months. The project focuses on improving productivity with a clean user experience, responsive design, and intuitive task planning workflow.
Built using React.js and Vite, the project demonstrates modern frontend development practices including component-based architecture, state management, dynamic rendering, responsive UI development, and deployment using GitHub and Vercel.

## Project Structure
## Project Structure
- `public/`  
  Stores static files and assets used by the application.
- `src/`  
  Contains the main source code of the Smart Planner application.
- `src/assets/`  
  Includes images, icons, and other reusable frontend assets.
- `src/App.jsx`  
  Main React component responsible for rendering the Smart Planner interface and handling application logic.
- `src/main.jsx`  
  Entry point of the React application that connects React with the HTML root element.
- `src/index.css`  
  Contains global styling and custom UI design for the application.
- `package.json`  
  Manages project dependencies, scripts, and project configuration.
- `vite.config.js`  
  Configuration file for Vite build and development environment.
- `README.md`  
  Project documentation containing setup instructions, features, and project overview.
